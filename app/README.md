# مینی‌اپ استخراج تندرست — نسخهٔ ۲.۲.۳

نسخهٔ دسکتاپ Python برای اجرا روی کامپیوتر شما، کنار سورس پنل مارک‌شو.

- [دانلود بستهٔ آماده](tanedorost-fast.zip)
- [راهنمای فارسی نصب، تنظیمات و بازیابی](README-fa.md)
- [موتور استخراج قابل جایگزینی در برنامهٔ قبلی](crawler/scraper.py)

```powershell
python -m pip install -r requirements.txt
python app.py
```

برای حفظ رابط قبلی، تنها `crawler/scraper.py` را جایگزین کنید؛ برای کنترل زمان انتظار و گزینه‌های جدید آپدیت، `app.py` جدید را هم استفاده کنید. این مینی‌اپ به نصب روی هاست PHP نیاز ندارد. فایل‌های خروجی و تنظیمات شخصی وارد Git نمی‌شوند.

گزارش `verification.json` مربوط به آزمون محلی است؛ سرعت سایت واقعی و اجرای رابط روی ویندوز هنوز تأیید نشده است.

در نسخهٔ جدید تمام دکمه‌های جدول سایز و پر شدن دیرهنگام `data-link` بررسی می‌شوند. زمان انتظار پیش‌فرض ۸ ثانیه و در رابط قابل تنظیم است. برای اصلاح جدول‌های خالی قبلی، حالت **به‌روزرسانی اطلاعات محصولات** را با تیک **بازخوانی محصولات قبلی** اجرا کنید؛ ادامهٔ معمولی آن‌ها را دوباره نمی‌خواند. فایل `app.py` جدید تنظیمات رابط را دارد.


نسخهٔ ۲.۲.۳: ساختار گالری اسپورت‌لند بدون `dv-product-gallery-main` پشتیبانی می‌شود. `main_image` لینک تصویر اصلی و `gallery` لینک تصاویر کامل سایت است؛ بندانگشتی‌های `_400` و تصاویر کپی‌شدهٔ اسلایدر وارد نمی‌شوند. لینک جدول سایز دیرهنگام هم با `size_guide` ثبت می‌شود. برای اصلاح خروجی‌های قبلی، حالت «به‌روزرسانی اطلاعات محصولات» و «بازخوانی محصولات قبلی» را فعال کنید و گزینه‌های «تصویر اصلی و تمام گالری سایت» و «جدول سایز» را تیک بزنید. سپس JSON جدید را از بخش تطبیق سایت، پیش‌نمایش و ثبت کنید. گزینهٔ دریافت موجودی سایت را خاموش نگه دارید تا موجودی مرکزی باقی بماند.

تصاویر از لینک اصلی سایت نمایش داده می‌شوند؛ نبودن توضیحات یا جدول سایز، حضور صفحه و تصاویرش در سایت را نفی نمی‌کند. شواهد مربوط به آخرین دریافت هستند و به‌تنهایی تضمین در دسترس‌بودن دائمی لینک تصویر نیستند. گالریِ دیرهنگام، در صورت خالی‌بودن اولیه، تا ۳ ثانیه مستقل از انتخاب جدول سایز منتظر می‌ماند. `verify_media.py` با HTML عمومیِ نمونهٔ اسپورت‌لند و صفحهٔ محلیِ دارای تأخیر اجرا می‌شود؛ دسترسی زنده به سایت در محیط تست تأیید نشده است.


اصلاح رنگ در نسخهٔ ۲.۲.۳: مقدار برچسب مستقیم رنگ در اسپورت‌لند و `data-tooltip` گزینهٔ فعال (`color-active`) خوانده می‌شود. اگر نشانگر فعال موجود نباشد، کد همان محصول یا گزینهٔ یکتای بدون لینک بررسی می‌شود؛ اولین رنگِ محصولات دیگر به‌جای رنگ جاری انتخاب نمی‌شود. ساختار قبلی تندرست حفظ شده است. برای اصلاح `color: null` در فایل قدیمی، حالت به‌روزرسانی با بازخوانی محصولات قبلی و تیک «رنگ» را اجرا کنید.


Version 2.2.2 always exports the product breadcrumb hierarchy as `category` (ordered array), `category_path` (slash-separated path), and `primary_category` (the final category). It omits home, generic catalog scaffolding and the product itself, and keeps one product trail instead of mixing duplicate breadcrumbs. Use Update with “refresh existing products” to repair an existing JSON, then preview/apply it in the panel. Website categories are stored separately from central ERP categories and are available to both portal and admin filters and chart rules.


### موجودی سایزها (۲.۲.۳)

`size_availability` وضعیت هر سایز، `available_sizes` و `unavailable_sizes` فهرست سایزهای موجود/ناموجود و `website_available` امکان خرید حداقل یک سایز را ثبت می‌کنند. `sizes` همچنان همهٔ سایزها را برای سازگاری نگه می‌دارد. مقدار نامشخص `null` است؛ موجودی ERP از این وضعیت‌ها بازنویسی نمی‌شود. ناموجودبودن کد اولیه یا یک سایز، عکس و حضور صفحه را حذف نمی‌کند. برای محصولات قبلی، حالت آپدیت و بازخوانی محصولات قبلی را با انتخاب «سایز» و «گالری» اجرا کنید.
