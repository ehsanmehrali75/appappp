# مینی‌اپ استخراج تندرست — نسخهٔ ۲.۱.۰

نسخهٔ دسکتاپ Python برای اجرا روی کامپیوتر شما، کنار سورس پنل مارک‌شو.

- [دانلود بستهٔ آماده](tanedorost-fast.zip)
- [راهنمای فارسی نصب، تنظیمات و بازیابی](README-fa.md)
- [موتور استخراج قابل جایگزینی در برنامهٔ قبلی](crawler/scraper.py)

```powershell
python -m pip install -r requirements.txt
python app.py
```

برای حفظ رابط قبلی، تنها `crawler/scraper.py` را جایگزین کنید؛ برای کنترل زمان انتظار و گزینه‌های جدید آپدیت، `app.py` جدید را هم استفاده کنید. این مینی‌اپ به نصب روی هاست PHP نیاز ندارد. فایل‌های خروجی و تنظیمات شخصی وارد Git نمی‌شوند.

گزارش `verification.json` مربوط به آزمون محلی است؛ سرعت سایت واقعی و اجرای رابط روی ویندوز هنوز تأیید نشده است.

در نسخهٔ جدید تمام دکمه‌های جدول سایز و پر شدن دیرهنگام `data-link` بررسی می‌شوند. زمان انتظار پیش‌فرض ۸ ثانیه و در رابط قابل تنظیم است. برای اصلاح جدول‌های خالی قبلی، حالت **به‌روزرسانی اطلاعات محصولات** را با تیک **بازخوانی محصولات قبلی** اجرا کنید؛ ادامهٔ معمولی آن‌ها را دوباره نمی‌خواند. فایل `app.py` جدید تنظیمات رابط را دارد.
