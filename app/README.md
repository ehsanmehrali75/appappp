# مینی‌اپ استخراج تندرست

نسخهٔ دسکتاپ Python برای اجرا روی کامپیوتر شما، کنار سورس پنل مارک‌شو.

- [دانلود بستهٔ آماده](tanedorost-fast.zip)
- [راهنمای فارسی نصب، تنظیمات و بازیابی](README-fa.md)
- [موتور استخراج قابل جایگزینی در برنامهٔ قبلی](crawler/scraper.py)

```powershell
python -m pip install -r requirements.txt
python app.py
```

برای استفاده در برنامهٔ فعلی، تنها `crawler/scraper.py` را جایگزین کنید. این مینی‌اپ به نصب روی هاست PHP نیاز ندارد. فایل‌های خروجی و تنظیمات شخصی وارد Git نمی‌شوند.

گزارش `verification.json` مربوط به آزمون محلی است؛ سرعت سایت واقعی و اجرای رابط روی ویندوز هنوز تأیید نشده است.
