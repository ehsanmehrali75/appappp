# نسخهٔ بهینهٔ مینی‌اپ استخراج تندرست

## نصب در برنامهٔ فعلی

قبل از جایگزینی، از پوشهٔ `output` و فایل قبلی `crawler/scraper.py` کپی پشتیبان بگیرید.
فقط فایل `crawler/scraper.py` این بسته را جایگزین همان فایل کنید. رابط گرافیکی قبلی شما بدون تغییر با این موتور کار می‌کند.

فایل `app.py` اختیاری است: نسخهٔ رابط ارسال‌شدهٔ شما با انتخاب هم‌زمانی ۱ تا ۸، گزینهٔ آپدیت واقعی، کپی گزارش و محدودکردن گزارش به ۲۰۰۰ خط. اگر رابط فعلی‌تان فایل‌ها یا امکانات دیگری دارد، صرفاً موتور را جایگزین کنید.

برای اجرای مستقل بسته در PowerShell، از داخل پوشهٔ بازشده:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Python 3.10 یا بالاتر پیشنهاد می‌شود. Chrome یا Edge نصب‌شده در مسیرهای معمول ویندوز استفاده می‌شود. اگر مرورگر شناسایی نشد، یکی از دو روش زیر کافی است:

```powershell
python -m playwright install chromium
```

یا مسیر واقعی مرورگر خود را مشخص کنید:

```powershell
$env:SCRAPER_BROWSER_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
python app.py
```

## تغییرات سرعت

- پیش‌فرض چهار دریافت هم‌زمان با یک browser context مشترک و تب‌های ثابت هر کارگر؛ اطلاعات نشست و locale یکسان می‌ماند.
- انتظار برای DOM و عناصر محصول به‌جای `networkidle`؛ اسکریپت، CSS، XHR و fetch حفظ می‌شوند.
- تصاویر، فونت و ویدیو دانلود نمی‌شوند؛ آدرس تصاویر گالری از HTML استخراج می‌شود. ظاهر صفحه در مرورگر مخفی هدف این ابزار نیست.
- اولین صفحهٔ دسته‌بندی دوباره دریافت نمی‌شود. با رسیدن به تعداد محصول بسته، کشف صفحات اضافی متوقف می‌شود. صفحه‌بندی جدید در Continue همچنان URLهای دریافت‌شده را رد می‌کند.
- هر محصول ابتدا در ژورنال کوچک نوشته و flush/fsync می‌شود؛ کل JSON هر ۱۰ محصول یا هنگام رسیدن نتیجهٔ بعدی پس از ۵ ثانیه و در پایان ذخیره می‌شود. دورهٔ ۵ ثانیه تایمر مستقل نیست.
- جست‌وجوی خطی محصولات قبلی با نگاشت URL جایگزین شده است.
- لاگ زمان کشف لینک‌ها، زمان هر محصول، تعداد موفق/ناموفق و زمان کل وجود دارد.

این نسخه مسیر HTTP یا API ساختگی اضافه نکرده است. برای حذف کامل مرورگر باید HTML/درخواست‌های واقعی سایت بررسی شوند.

## ادامه، آپدیت و حفظ اطلاعات

- `fresh`: خروجی جدید می‌سازد. پیش از اولین نتیجهٔ موفق، JSON قبلی دست نمی‌خورد؛ در اولین ذخیره، کپی `.bak` آن تهیه می‌شود. اگر همهٔ محصولات انتخابی شکست بخورند، خطا اعلام می‌شود و JSON قبلی حفظ می‌شود.
- `continue`: خروجی و ژورنال را بازیابی می‌کند و فقط URLهای جدید/ناموفق را دریافت می‌کند.
- `update`: برای سازگاری دقیق با کد قبلی، پیش‌فرض مانند Continue فقط URLهای جدید را می‌خواند. برای تازه‌کردن محصولات موجود، تیک «در حالت آپدیت، اطلاعات محصولات قبلی هم تازه شود» را در رابط جدید فعال کنید؛ یا `refresh_existing=True` به موتور بدهید.
- در آپدیت واقعی، فیلدهایی که انتخاب نکرده‌اید حفظ می‌شوند. محصولات ناموفق جایگزین نمی‌شوند.
- درصد پیشرفت مربوط به تعداد تلاش‌های تکمیل‌شده است؛ تعداد موفق و خطا جدا در گزارش نوشته می‌شود. در شکست جزئی، مسیر فایل نتیجه برگردانده می‌شود؛ گزارش را برای تعداد خطا ببینید.
- Pause دریافت‌های تازه را متوقف می‌کند؛ درخواست‌های در حال اجرا ممکن است تمام و ذخیره شوند. فقط پس از Resume کار جدید شروع می‌شود.

ژورنال `output/products.json.journal.jsonl` کنار JSON نگه داشته می‌شود. بعد از بسته‌شدن ناگهانی، همان پوشه و مسیر را با Continue اجرا کنید. ژورنال و JSON را جدا از هم جابه‌جا، پاک یا ویرایش نکنید. فایل `.lock` می‌تواند باقی بماند؛ قفل سیستم‌عامل پس از بسته‌شدن پردازش آزاد می‌شود و لازم نیست این فایل را دستی حذف کنید. خروجی آسیب‌دیده بدون هشدار به آرایهٔ خالی تبدیل نمی‌شود.

## تنظیمات پیشرفتهٔ اختیاری

پارامترهای قبلی `run_scraper` حفظ شده‌اند. گزینه‌های جدید فقط keyword هستند:

```python
await run_scraper(
    url=url, mode="update", fields=["name", "price", "sizes"],
    log=log, progress=progress, batch_size=50,
    controller=scraper_controller, use_system_proxy=True,
    concurrency=4, refresh_existing=True,
    checkpoint_every=10, timeout_ms=20000, dynamic_wait_ms=800, block_assets=True,
)
```

اگر داده‌ها با تأخیر جاوااسکریپت ساخته می‌شوند، `dynamic_wait_ms` را بیشتر کنید. اگر بخشی از سایت به لودشدن واقعی تصویر وابسته بود، `block_assets=False` بدهید. نبودن عناصر اختیاری مثل گالری یا جدول سایز می‌تواند تا این مهلت انتظار ایجاد کند. تنظیمات selectors همان فایل اصلی شماست؛ ساختار جدید سایت ممکن است به اصلاح آن‌ها نیاز داشته باشد. در صورت محدودیت یا خطاهای سایت، هم‌زمانی را به ۱ یا ۲ کاهش دهید. گزینهٔ پروکسی مثل قبل، تنظیمات مرورگر سیستم را حفظ یا صریحاً غیرفعال می‌کند؛ وضعیت VPN را تغییر نمی‌دهد.

## آنچه بررسی شده است

گزارش `verification.json` مقایسهٔ نسخهٔ اصلی و جدید روی سایت آزمایشی محلی است. سایت واقعی تندرست، پروکسی ویندوز و قفل ویندوز در این محیط آزمایش نشده‌اند. بهبود سرعتِ گزارش محلی تضمین سرعت سایت واقعی نیست. موتور در Chromium روی لینوکس آزموده شده؛ رابط PyQt در این محیط فقط بررسی نحوی شده است.

برای شروع روی سیستم خودتان، هم‌زمانی ۲ و یک دستهٔ کوچک را اجرا و نام، قیمت، سایز و گالری را با چند صفحهٔ واقعی مقایسه کنید؛ بعد آن را به ۴ افزایش دهید.


برای تکرار آزمون محلی بعد از نصب وابستگی‌ها:

```powershell
python verify_local.py
```

این آزمون فقط یک وب‌سرور موقت روی دستگاه خودتان می‌سازد و به سایت واقعی درخواست نمی‌فرستد. فایل اصلی شما برای مقایسه در `reference/original_scraper.py` نگه داشته شده است.


## خروجی برای تکمیل پنل

موتور دیگر فیلتر `stock=1` را خودکار به لینک دسته‌بندی اضافه نمی‌کند. اگر خود لینک ورودی فیلتر موجودی داشته باشد، همان فیلتر حفظ می‌شود. خروجی یک دسته‌بندی، بستهٔ محدود یا اجرای دارای خطا، مدرک نبودن محصول در کل سایت نیست.

برای ورود به پنل از بخش «تکمیل اطلاعات و تطبیق با سایت» استفاده کنید. این مسیر فقط محصولات موجود را تکمیل می‌کند؛ قیمت و موجودی صریح قابل انتخاب هستند، اما تیام مرجع ایجاد محصولات و تنوع‌ها باقی می‌ماند. گزینهٔ بررسی غیبت فقط برای خروجی واقعاً کامل همان پروژه است.
