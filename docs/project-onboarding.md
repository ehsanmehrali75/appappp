# خرید و راه‌اندازی پروژه

خرید جدید فقط پس از تأیید واقعی درگاه پروژه ایجاد می‌کند. تکرار callback یا ثبت دوبارهٔ همان خرید پروژهٔ تکراری نمی‌سازد. مدیر اصلی می‌تواند بدون پرداخت پروژه بسازد؛ کاربران دیگر از خرید پروژه وارد می‌شوند. رسیدهای قدیمی فاقد رکورد تأیید خصوصی، خودکار پروژه ایجاد نمی‌کنند و باید توسط پشتیبانی بررسی شوند.

بعد از ساخت، راهنمای راه‌اندازی باز می‌شود و از تنظیمات پروژه دوباره قابل دسترسی است. مراحل شامل هویت و بستر، موجودی، دریافت وب‌سایت، هوش مصنوعی، شبکه‌های اجتماعی، سئو، گردش تأیید و مرور نهایی است. مراحل با امکانات پلن تنظیم می‌شوند و امکان رد کردن، توقف و ادامه دارند. امکانات واقعی هر پلن در مدیریت پلن‌ها مشخص می‌شود؛ تغییر پلن، سقف خریدهای قبلی را بازنویسی نمی‌کند.

انتخاب یک روش با اتصال موفق تفاوت دارد. تنظیمات انتخاب‌شده، نتیجهٔ تست و دیتای دریافت‌شده جدا نمایش داده می‌شوند. وردپرس از افزونه، تیام از ایجنت شبکهٔ فعلی کاربر و ورود دستی از Excel/JSON استفاده می‌کنند. اتصال ChatGPT اختیاری است و گزارش خودکار به API با هزینهٔ جدا نیاز دارد.

کراول اولیه در صف cron اجرا می‌شود و خروجی وب‌سایت را جدا ذخیره می‌کند. فایل دریافت‌شده از مسیر پیش‌نمایش واردسازی موجود بررسی می‌شود؛ کراول اولیه مستقیماً موجودی ERP یا تصاویر داخلی را جایگزین نمی‌کند. سایت‌های وابسته به جاوااسکریپت می‌توانند از اپ دسکتاپ استفاده کنند.

برای استقرار، درگاه واقعی و cron باید روی هاست تنظیم باشند. تست‌های خودکار از بانک شبیه‌سازی‌شده، دیتابیس جدا و منابع مصنوعی استفاده می‌کنند؛ هیچ پرداخت واقعی یا اتصال خصوصی تیام در تست انجام نمی‌شود.
