# قرارداد گزارش موجودی تیام — شرح محصول و شرح رنگ

ساختار تأییدشدهٔ گزارش فعلی همان ۱۲ ستون زیر است و نیازی به ساخت کد جداگانهٔ مدل یا رنگ ندارد:

| ستون | کاربرد |
|---|---|
| ProCode | کد مستقل هر سایز؛ متن باشد تا صفر ابتدای کد حفظ شود |
| ProDes | شرح مدل؛ برای سایزهای همان مدل یکسان باشد |
| Color | شرح رنگ؛ هر ترکیب مدل و رنگ یک محصول مستقل است |
| Size | سایز واقعی همان کد |
| ShopCode / ShopName | کد و نام شعبه |
| StockTedad | موجودی همان کد در همان شعبه؛ اعشاری و صفر معتبر، NULL نامعتبر |
| Category / SubCategory / ProductType | اطلاعات طبقه‌بندی منبع |
| Grade | مشخصهٔ منبع؛ معنای آن فرض نمی‌شود |
| LastUpdateDateTime | زمان به‌روزرسانی منبع؛ منطقهٔ زمانی مشخص باشد |

هر ProCode باید در تمام شعب به یک شرح مدل، رنگ و سایز مشخص اشاره کند. برای هر کد و شعبه فقط یک ردیف موجودی وجود داشته باشد و joinها موجودی را چندبرابر نکنند. گزارش کامل شعب مورد توافق، شامل ردیف‌های موجودی صفر باشد؛ فیلترهای گزارش اعلام شوند.

فاصله‌های اضافه، حروف عربی/فارسی و فاصلهٔ اطراف خط تیره در هویت رنگ یکسان‌سازی می‌شوند؛ رنگ مرکب مانند «سیاه-سفید» یک رنگ مستقل باقی می‌ماند. تغییر شرح مدل یا رنگ را کنترل‌شده اعلام کنید تا تطبیق اطلاعات قدیمی بررسی شود.

قیمت در این گزارش وجود ندارد؛ قیمت‌های فعلی پنل حفظ می‌شوند. همگام‌سازی فقط پس از پیش‌نمایش و تأیید نگاشت فعال می‌شود. کاربر SQL صرفاً مجوز SELECT روی ویو دارد.
