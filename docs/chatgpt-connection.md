# اتصال ChatGPT و گزارش هوشمند مارکشو

ورود پنل: `/panel/ai-connect.php?project=PROJECT_ID`؛ پیوند در ادمین و دسترسی سریع پورتال اضافه شده است.

## قابلیت‌ها

- اتصال مستقل حساب پنل هر کاربر برای هر پروژه، OAuth Authorization Code، PKCE S256 برای کلاینت عمومی MCP، Client Secret برای GPT Actions، توکن یک‌ساعته و refresh چرخشی سی‌روزه.
- خواندن شناخت پروژه، شمارش دقیق صف‌های مشترک ادمین/پورتال، محصولات و موجودی، تصاویر اصلی/گالری و جدول سایز پنل و سایت، فروش ثبت‌شده شعبات و تقویم. کلیدها و تنظیمات اتصال پروژه خروجی داده نمی‌شوند.
- منابع JSON/CSV برای موجودی شعبات، فروش/تبلیغات، GA4، Search Console و دادهٔ سفارشی با نام، منشأ، واحد و ستون تاریخ. اتصال مستقیم به API گوگل در این نسخه نیست؛ دادهٔ نمایشی/آزمایشی انبار قدیمی سئو به‌عنوان دادهٔ واقعی ارائه نمی‌شود.
- ذخیرهٔ عکس اصلی، گالری، سوشیال، جدول سایز، توضیحات و تحلیل در محصول/پروژهٔ موجود. انتخاب دقیق product_id یا SKU/رنگ؛ عدم ایجاد محصول تازه. عکس‌های قبلی حفظ و تصاویر تولیدشده تأییدنشده ثبت می‌شوند.
- منابع API شخصی یا سرویس اعتباری پنل؛ مالک، پروژه‌های مجاز و نام‌های کاربری مصرف‌کننده را تعیین می‌کند. اشتراک منبع API هیچ دسترسی تازه‌ای به دادهٔ پروژه ایجاد نمی‌کند. هویت مالک و نویسندهٔ برنامه هنگام اجرا دوباره اعتبارسنجی می‌شود.
- گزارش روزانه/هفتگی به وقت تهران؛ منابع انتخابی، بازهٔ تاریخ میلادی، دستور تحلیل، snapshot مبنا و مصرف واقعی همراه گزارش ذخیره می‌شوند. برای محدود کردن هزینه، گزارش API حداکثر ۱۰۰ ردیف هر منبع (حداکثر ۸ منبع) و شمارش دقیق صف‌ها را می‌بیند. نمونه‌بودن در داده و دستور تحلیل مشخص است. ChatGPT تعاملی می‌تواند همهٔ صفحات را بخواند.
- کیف پول به ریال، پرداخت زرین‌پال با تأیید سمت سرور، دفتر مصرف و رزرو سقف هزینه پیش از API. محیط sandbox اعتبار واقعی نمی‌سازد. کلید شخصی از کیف پول پنل هزینه‌ای کم نمی‌کند؛ هزینهٔ آن مستقیماً در حساب OpenAI مالک است.

## استقرار روی هاست اشتراکی

PHP 8.0+ با post_max_size حداقل 16M، upload_max_filesize حداقل 8M، OpenSSL، cURL، mbstring، fileinfo و پشتیبانی تصاویر لازم است. برای تصاویر WebP، پشتیبانی ابزارهای موجود وب‌سایت نیز فعال باشد. هاست باید خروجی HTTPS به OpenAI و زرین‌پال داشته باشد. تأیید TLS هرگز غیرفعال نمی‌شود.

1. تمام فایل‌ها از جمله `.htaccess` ریشه و فایل‌های `panel/inc/ai` منتشر شوند. قانون انتقال Authorization در تنظیمات Apache/FastCGI باید فعال باشد؛ این هدر نباید حذف شود. سرور باید `PATH_INFO` برای `/panel/ai_api.php/TOOL_NAME` را پشتیبانی کند (`AcceptPathInfo On`).
2. `MAARKSHO_AI_PUBLIC_BASE=https://maarksho.com` دامنهٔ ثابت HTTPS است؛ برای دامنهٔ دیگر صریحاً تغییر دهید. آدرس‌ها از هدر ورودی Host ساخته نمی‌شوند.
3. پیش‌فرض فضای خصوصی `panel/db/ai-private` با مجوز 0700 و مسدودسازی وب است. ترجیحاً `MAARKSHO_AI_STATE_DIR=/home/ACCOUNT/private/maarksho-ai` را بیرون public_html تنظیم کنید. مسیر یکسان باید برای PHP وب و Cron استفاده شود. state و master.key را با هم در نسخهٔ پشتیبان خصوصی نگه دارید؛ گم‌شدن کلید، منابع API را غیرقابل بازیابی می‌کند. فایل‌ها را در Git قرار ندهید.
4. مدیر اصلی در تب «منابع API» کلید، مدل قابل دسترس حساب و در صورت ارائهٔ سرویس اعتباری، تعرفهٔ ریالی یک میلیون توکن ورودی/خروجی را تنظیم کند. تعرفهٔ ثابت دلار یا نرخ تبدیل فرضی در کد وجود ندارد. سقف روزانهٔ توکن منبع بر اساس روز UTC محاسبه می‌شود. مجوز پروژه‌ها و نام‌های کاربری را محدود کند. کاربران عادی می‌توانند کلید شخصی خودشان را اضافه و به افراد/پروژه‌های مجازشان اشتراک دهند.
5. برای پرداخت واقعی تنظیمات زرین‌پال موجود سایت شامل merchant_id معتبر، فعال‌بودن درگاه، IRR/IRT و غیرفعال‌بودن sandbox تکمیل شود. شارژ، اعتبار سرویس **مارکشو** است؛ شارژ حساب OpenAI یا اشتراک ChatGPT نیست.
6. Cron در cPanel، مثلاً هر ۵ دقیقه:

```cron
*/5 * * * * /usr/local/bin/php /home/ACCOUNT/public_html/panel/ai_report_worker.php >> /home/ACCOUNT/private/ai-cron.log 2>&1
```

مسیر PHP و ACCOUNT واقعی هاست جایگزین شود. Worker عمومی HTTP نیست؛ در هر اجرا حداکثر ۵ برنامه بررسی می‌کند. برای تعداد زیاد برنامه‌ها اجرای بیشتر یا worker مناسب لازم است. اجرای ازدست‌رفته یک بار با دادهٔ فعلی انجام می‌شود؛ گزارش تاریخی ساختگی تولید نمی‌شود. روزانه/هفتگی بر اساس ساعت تهران برنامه‌ریزی می‌شود.

## راه‌اندازی داخل ChatGPT

این اتصال، جایگزین امروزی پلاگین قدیمی است. انتشار عمومی در فروشگاه ChatGPT انجام نشده؛ اپ سفارشی یا GPT اختصاصی هر کاربر/فضای کاری تنظیم می‌شود. وجود Developer Mode، اپ سفارشی و قابلیت ابزارهای نوشتن به طرح، رابط و سیاست workspace ChatGPT بستگی دارد.

### اپ MCP

- URL: `https://maarksho.com/panel/ai_mcp.php`
- OAuth issuer: `https://maarksho.com`
- Discovery: `/.well-known/oauth-authorization-server`
- Resource metadata: `/.well-known/oauth-protected-resource/panel/ai_mcp.php`
- Transport: stateless Streamable HTTP با پاسخ JSON؛ GET/SSE ارائه نمی‌شود.
- ابتدا callback واقعی اعلام‌شدهٔ ChatGPT را در تب «اتصال ChatGPT» ثبت کنید؛ نوع عمومی MCP با S256 را انتخاب کنید. Client ID را در تنظیمات OAuth اپ وارد کنید. ثبت خودکار و عمومی کلاینت (DCR) فعال نیست. اگر رابط ChatGPT ورود Client ID دستی را پشتیبانی نکند، از GPT Actions استفاده کنید؛ آدرس callback را حدس نزنید.
- سپس اتصال را آغاز کنید، با حساب پنل وارد باشید، پروژه و دامنه‌ها را تأیید کنید. برای پروژهٔ دیگر یک اتصال مستقل بسازید. نام اپ‌ها را مشخص و یکتا بگذارید.

### GPT Actions

در GPT Builder، Actions → Import schema:
`https://maarksho.com/panel/ai_api.php?schema=openapi`

احراز هویت OAuth با Client ID و Client Secret اختصاصی، token exchange به روش POST یا Basic:

- Authorization URL: `https://maarksho.com/panel/ai_oauth.php?action=authorize`
- Token URL: `https://maarksho.com/panel/ai_oauth.php?action=token`
- Scope خواندن: `project.read`
- دامنه‌های اختیاری نوشتن: `content.write reports.write datasets.write`

نوع اپ «GPT Actions با Client Secret» را در پنل انتخاب کنید. Callback دقیق همان GPT را ثبت کنید. متن پیشنهادی دستورهای GPT در `integrations/chatgpt/instructions.fa.md` است. Client Secret فقط زمان ساخت نمایش داده می‌شود؛ در صورت گم‌شدن اپ جدید بسازید. حساب ChatGPT/رمز آن در پنل دریافت یا ذخیره نمی‌شود.

فایل‌های تولیدشده در ChatGPT همیشه لینک قابل دانلود سمت سرور ندارند. ابزار عکس لینک عمومی مستقیم HTTPS، base64 و file reference دارای download_link را قبول می‌کند؛ پشتیبانی رابط از ارسال file reference باید عملاً بررسی شود. لینک sandbox قابل دریافت نیست. جایگزین آماده، فرم «ثبت فایل تولیدشده» در پنل است. URL خصوصی شبکه، redirect، فایل غیرتصویر و تصویر بیش از ۸ مگابایت یا ۴۰ مگاپیکسل رد می‌شود. اصلی و گالری همان روند تأیید پورتال را دارند.

## خطا، لغو مجوز و مصرف

با حذف/ریست حساب، تغییر رمز یا حذف مجوز، توکن قبلی نمی‌تواند به داده دسترسی داشته باشد. لغو اتصال از پنل نیز فوری است. حذف اپ، اتصال‌های تمام پروژه‌های آن اپ را لغو می‌کند. حذف/ریست پروژه داده‌ها، برنامه‌ها و مجوزهای AI آن را پاک می‌کند؛ دفتر مالی حساب حفظ می‌شود.

هر ثبت محتوا/گزارش `request_id` یکتا دارد. تکرار همان شناسه و همان payload همان نتیجه را می‌دهد؛ payload متفاوت با شناسهٔ قبلی رد می‌شود. در UI، تکرار ارسال اجرای دستی همان فرم هزینهٔ تازه‌ای ایجاد نمی‌کند. اجرای Cron هم با شناسهٔ برنامه/موعد یکتا کنترل می‌شود.

در قطع ارتباط پس از ارسال API، امکان مصرف در OpenAI وجود دارد؛ درخواست همان موعد دوباره اجرا نمی‌شود. اعتبار رزروشده تا بررسی مدیر اصلی باقی می‌ماند. در تب «اعتبار و مصرف» مدیر اصلی پس از مشاهدهٔ مصرف OpenAI می‌تواند هزینهٔ واقعی را ثبت یا رزرو را آزاد کند. اجرای متوقف‌شده بیش از ۱۰ دقیقه در اجرای بعدی Worker نامشخص می‌شود. این وضعیت نباید با تکرار کورکورانه رفع شود.

## اعتبارسنجی

تست‌ها روی کپی موقت و دادهٔ ساختگی اجرا می‌شوند؛ OAuth/HTTP واقعی محلی، جداسازی کاربران/پروژه‌ها، محدودیت دامنه، ثبت محتوا/تأیید تصویر، رزرو و تسویه و پاسخ جعلی کنترل‌شدهٔ OpenAI/زرین‌پال. این تست‌ها پرداخت یا هزینهٔ واقعی ایجاد نمی‌کنند. اتصال زندهٔ ChatGPT، حساب OpenAI و callback درگاه به تنظیمات حساب و استقرار دامنه وابسته است و باید پس از تنظیم موارد بالا آزمایش شود؛ صرف push به GitHub آن‌ها را فعال نمی‌کند.
