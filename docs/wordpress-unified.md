# اتصال واحد وردپرس — افزونهٔ نسخهٔ ۶

برای پروژه با بستر WordPress، افزونه مرجع محصولات، موجودی، قیمت، عکس اصلی و گالری، نوشته‌ها، برگه‌ها، دسته‌بندی/برچسب نوشته و محصول و متادیتای سئو است. گام کراول از راه‌اندازی حذف می‌شود و مسیرهای استخراج/خروجی قدیمی ادمین به صفحهٔ اتصال وردپرس می‌روند. تیام و سایت اختصاصی مسیرهای فعلی خود را دارند.

## نصب

1. در پروژه ← اتصال وردپرس، افزونه را دانلود و روی سایت نصب/به‌روز کنید.
2. آدرس HTTPS وردپرس را ذخیره کنید. پنل توکن API می‌سازد؛ آن را در افزونه، «توکن API پنل» قرار دهید. فیلدهای ارسال قدیمی به مرکز داده برای این روش لازم نیستند؛ گزینهٔ ارسال قدیمی را خاموش بگذارید.
3. اگر اصلاحات باید از پنل به سایت بروند، اجازهٔ نوشتن را در افزونه فعال کنید. تست پنل خواندن واقعی API و قابلیت‌های اعلام‌شدهٔ افزونه را بررسی می‌کند؛ تست خواندن، تضمین موفقیت انتشار نیست.
4. «دریافت کامل» همهٔ بخش‌های مجاز را بسته‌به‌بسته دریافت می‌کند. توقف/قطع صفحه داده‌های ثبت‌شده را حذف نمی‌کند؛ دریافت از آخرین صفحه ادامه دارد. دریافت یک صفحه، دریافت کامل سایت محسوب نمی‌شود.
5. برای ادامهٔ دریافت و ارسال خودکار، Cron موجود پنل را هر ۱ تا ۵ دقیقه اجرا کنید. در پروژه، دریافت خودکار و ارسال پس از تأیید را روشن کنید. Worker با هویت مدیر تنظیم‌کننده اجرا می‌شود و مجوزهای فعلی او دوباره بررسی می‌شوند.

## کتابخانه و ارسال

محصول/تنوع با شناسهٔ ثابت وردپرس و شناسهٔ پروژه نگاشت می‌شود؛ تطبیق حدسی اسم انجام نمی‌شود. محصول جدید در کتابخانه ایجاد و موجودی/قیمت از ووکامرس خوانده می‌شود. stock_status ووکامرس برای محصولات بدون مدیریت تعداد، با عدد ساختگی جایگزین نمی‌شود. رکوردهای محصول و تنوع مستقل وردپرس و ارتباط parent_id نگه داشته می‌شوند.

تصاویر منتشرشدهٔ سایت نیاز به تأیید مجدد ندارند. عکس دستی ردشده یا در انتظار تأیید، با دریافت بعدی سایت بازنویسی نمی‌شود. فایل اصلی باکیفیت پنل پس از ارسال نیز حفظ می‌شود. عکس رفرنس و سوشیال در مجموعهٔ عکس وب‌سایت فرستاده نمی‌شوند. تصاویر باید URL عمومی HTTPS داشته باشند تا وردپرس بتواند آن‌ها را وارد کتابخانهٔ رسانه کند.

پس از تأیید نهایی، تغییرات تصویر در صف قرار می‌گیرند؛ تنها پاسخ موفق افزونه، رسید ارسال محسوب می‌شود. تغییر URL تصویر بعد از ورود به رسانهٔ وردپرس، نباید یک حلقهٔ ارسال تازه بسازد. درخواست‌ها شناسهٔ ثابت دارند و تکرار یک درخواست، محتوای یکسان را دوباره تغییر نمی‌دهد. ارسال به محصول زباله‌دان متوقف می‌شود. غیبت از یک صفحهٔ API، مجوز صفر کردن موجودی یا حذف تصاویر نیست. پس از دریافت کامل، رکورد غایب علامت «در فهرست کامل دیده نشده» می‌گیرد؛ سابقه و فایل‌های اصلی حفظ می‌شوند، موجودی به‌جای صفر «نامشخص» و ارسال تا بررسی متوقف می‌شود. این وضعیت در انبار تحلیلی با status=not_seen و in_latest_snapshot=false ثبت می‌شود. چنین رکوردی فرصت سئوی فعال محسوب نمی‌شود. داده‌های دریافت‌شده با شناسه upsert می‌شوند.

ویرایش محصول و تصاویر از کتابخانه ممکن است؛ ویرایش متن/سئو محصول، نوشته، برگه و دسته‌بندی در صفحهٔ وردپرس پیش‌نمایش و تأیید دارد. قیمت از مسیر ویرایش محصول موجود پنل قابل تغییر است. پنل به‌صورت خودکار وضعیت draft را publish نمی‌کند و آرشیو یا دسته‌بندی محصول را با تطبیق نام تغییر نمی‌دهد. نسخهٔ آخرین ویرایش سایت در درخواست ارسال می‌شود. تغییر هم‌زمان در وردپرس خطای 409 می‌دهد؛ باید نسخهٔ تازه دریافت و اصلاحات دوباره بررسی شوند. خطا یا قطع ارتباط، به معنی موفق بودن ارسال نیست؛ تلاش مجدد با همان شناسه انجام می‌شود.

جدول سایزِ تولیدشده در فیلد `maarksho_size_chart_url` افزونه ثبت و در تب راهنمای سایز ووکامرس نمایش داده می‌شود. افزونه فیلد افزونه‌های دیگرِ جدول سایز را حدس نمی‌زند. نوشته‌های بلوکی و HTML اصلی دریافت می‌شوند؛ این مسیر بررسی HTML رندرشدهٔ صفحه توسط مرورگر نیست.

## سئو، تحلیل و AI

صفحهٔ فرصت‌ها موارد بیش از ۳۰ روز بدون ویرایش و عنوان/توضیح سئوی ناقص را نشان می‌دهد؛ تاریخ نامشخص با محتوای قدیمی یکی گرفته نمی‌شود. تاریخ ویرایش دسته‌بندی‌های قدیمی پس از اولین ویرایش با افزونه ثبت می‌شود. Rank Math برای محتوا و taxonomy خوانده/ویرایش می‌شود؛ متادیتای خواندنی Yoast برای نوشته/محصول هم صادر می‌شود.

برای آمار جست‌وجو و بازدید، منابع Google/Composio موجود مرکز داده باید جداگانه مجوز بگیرند. افزونهٔ وردپرس به‌تنهایی دسترسی Search Console یا GA4 ایجاد نمی‌کند. یک منبع GSC و یک منبع GA4 انتخاب می‌شود؛ دادهٔ ۲۸ روز کامل تا دیروز بر اساس URL به محتوا وصل می‌شود. نبود منبع یا ردیف تحلیلی با صفر جایگزین نمی‌شود. نمایش حداقل ۱۰۰ و CTR کمتر از ۲٪ فقط یک قاعدهٔ قابل بررسی است، نه تضمین رشد یا رتبه.

برنامهٔ بازبینی به‌عنوان پیشنهاد قاعده‌محور ذخیره می‌شود، JSON دارد و خودکار منتشر نمی‌شود. با مجوز اتصال هوشمند، داده‌های API در همان انبار دادهٔ پروژه برای ابزارهای ChatGPT و گزارش‌های API موجود در دسترس‌اند؛ برنامهٔ بازبینی نیز به گزارش‌های پروژه اضافه می‌شود. متن خیلی طولانی در نسخهٔ تحلیلی با پرچم content_truncated محدود می‌شود؛ سند اصلی در فضای وردپرس حفظ می‌شود. استفاده از API هوش مصنوعی و گزارش زمان‌بندی‌شده همچنان به کلید/اعتبار و تنظیم گزارش نیاز دارد.

## اعتبارسنجی

تست‌ها از وردپرس/ووکامرس شبیه‌سازی‌شده، دیتابیس جدا و API مصنوعی استفاده می‌کنند. تست مرورگر اتصال، دریافت کامل، انتقال محصول، پیش‌نمایش/تأیید، رسید ارسال، فیلتر محتوای قدیمی و موبایل را بررسی می‌کند. انتشار یا دریافت واقعی از سایت مشتری در محیط توسعه انجام نشده است؛ پس از نصب نسخهٔ ۶، تست واقعی خواندن و یک ارسال آزمایشی روی محتوای انتخابی را در پنل اجرا کنید.
